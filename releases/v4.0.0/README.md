# Google Drive Desktop Backup Manager v4.0.0

> 歷史版本：已由 [v4.0.1](../v4.0.1/) 取代，不應用於新安裝。

v4.0.0 首次加入 MirrorSafe，但 repository 中的歷史 Base64 分段有完整性異常，重組結果不符合公告 SHA-256；還原腳本在 Windows PowerShell 5.1 也可能遇到 UTF-8 編碼解析問題。

為避免新使用者取得無法驗證的安裝包，本版本不再提供安裝指引。請改用 v4.0.1 的完整 ZIP、SHA-256 清單與安裝說明。

v4.0.0 的檔案只保留供版本稽核，不代表可用的正式下載來源。
